# Settlement selection artwork

Five original AI-generated painted atlas illustrations created for Landwright's settlement type buttons. These are archetype illustrations for the selector; actual map previews and saved layouts are terrain-aware procedural geometry.

The original square PNG illustrations remain in the session's `/workspace/generated_images/` directory. The shipped files are WebP encodings at the same dimensions, quality86, with no crop. Images load lazily and decode asynchronously when the selector is used. Total shipped artwork is approximately3.4MiB.

Art direction: muted olive meadows, warm thatch/tile roofs, ink contours, stone architecture; Hamlet cottages, Village river lane, Town market square, Abbey cloister and Castle keep/walls. Do not revert to rendering tiny map-scale roof geometry into these cards. Keep all five buttons the same dimensions at each sidebar width, including Castle.
