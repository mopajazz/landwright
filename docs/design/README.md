# Woodland art direction

[woodland-direction.png](woodland-direction.png) is the user-approved generated concept for terrain-integrated woodland. It is **not an application screenshot**, a shipped renderer, or an asset to paste over the map.

The user rejected v2.3's outlined pine/round-canopy stamps as too cartoony. The approved direction is muted, overlapping canopy masses with irregular edges, soft contact shadows, natural gaps and grassy clearings that follow the relief. Implement this procedurally from the saved forest density while keeping ground edits, saves, erasing and Undo intact.

Judge the implementation using actual screenshots and exports. The first v2.4 attempt looked uniformly beaded; the working version varies crown positions/radii and softens lighting. Compare 2D and 3D views before release. The old `/workspace/shared/landwright-forests.jpg` shows rejected v2.3 stamps and must not be presented as the new renderer.
